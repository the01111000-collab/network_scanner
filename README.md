# Home Network Health Scanner

โปรแกรมนี้จะทำงานโดยที่จะสแกนเน็ตบ้านของตัวเอง เพื่อเรียนรู้ดูว่ามีอุปกรณ์ไหนออนไลน์ และเปิดพอร์ตอะไรอยู่ แล้วสรุปเป็นรายงานสุขภาพของเครือข่ายเน็ตบ้านของตัวเอง

## ทำงานยังไง

1. สั่ง ping ไปที่เครื่องเป้าหมาย 1 ครั้ง (`-n 1`) รอคำตอบไม่เกิน 500 มิลลิวินาที (`-w 500`) แล้วดูว่ามี `TTL` กลับมาไหม ถ้ามีเท่ากับออนไลน์

2. ต่อไปจะเช็กพอร์ตด้วยการลองเชื่อมต่อไปที่พอร์ต 22, 53, 80, 443, 3389 ด้วยเครื่องมือ `socket` และใช้ฟังก์ชัน `connect_ex` ถ้าพอร์ตเปิดอยู่ จะได้ผลลัพธ์เป็น 0 แสดงว่าเชื่อมต่อสำเร็จ

   พอร์ตใช้ทำอะไร
   - 22 SSH ควบคุมเครื่องผ่านคำสั่ง
   - 53 DNS แปลงชื่อเว็บเป็น IP
   - 80 เว็บแบบไม่เข้ารหัส (HTTP)
   - 443 เว็บแบบเข้ารหัส (HTTPS)
   - 3389 Remote Desktop ควบคุมหน้าจอจากที่อื่น

3. ระหว่างสแกน โปรแกรมจดเครื่องที่ online ลงใน list `online_hosts` และจดคู่ (IP, พอร์ต) ที่เปิดอยู่ลงใน list `open_ports` พอสแกนเสร็จจะพิมพ์รายงานบอกเวลาที่ใช้ จำนวนและรายชื่อเครื่องที่ online และพอร์ตที่เปิดอยู่

## เครื่องมือที่ใช้

- `subprocess` เครื่องมือสำหรับสั่งรันคำสั่งของ Windows (เช่น ping) จากใน Python
- `socket` เครื่องมือสำหรับเชื่อมต่อเครือข่าย ใช้ "เคาะประตู" port ของเครื่องอื่น
- `time` เครื่องมือจับเวลา (`time_start = time.time()`)

## วิธีรัน

ใช้ Windows + Python 3 ถ้าเครือข่ายต่างจาก `192.168.1.` ให้แก้ `prefix` ในโค้ดก่อน แล้วพิมพ์

```
python scanner.py
```

## ตัวอย่างผลจริง (15 พ.ย. 2569)

```
===== Health Report =====
scan finished in 141.65 seconds
online hosts: 8: ['192.168.1.1', '192.168.1.34', '192.168.1.36', '192.168.1.38', '192.168.1.39', '192.168.1.42', '192.168.1.43', '192.168.1.45']
open ports: 2: [('192.168.1.1', 53), ('192.168.1.1', 80)]
```

สแกนครบ 254 IP ใช้เวลาประมาณ 2.4 นาที เจออุปกรณ์ online 8 เครื่อง มีแค่ Router 192.168.1.1 ที่เปิดพอร์ต 53 (DNS) กับ 80 (หน้าตั้งค่า Router) ส่วนอีก 7 เครื่องปิดทั้ง 5 พอร์ต ถือว่าสุขภาพดี เพราะไม่มีพอร์ตเสี่ยงอย่าง 22 หรือ 3389 เปิดทิ้งไว้ ข้อสังเกตคือหน้าตั้งค่า Router ใช้พอร์ต 80 ซึ่งไม่เข้ารหัส

## ปัญหาที่เจอและวิธีแก้

เครื่องตัวเองขึ้นว่า offline ตอนสแกนทั้งวง IP 192.168.1.49 ที่เคยเป็นของคอมผมกลับขึ้นว่า offline ผมเลยเช็ก IP ปัจจุบันด้วย `ipconfig` พบว่าวันนั้นเป็น 192.168.1.43 ซึ่งอยู่ในรายชื่อที่สแกนเจอ สาเหตุคือ Router แจก IP ด้วย DHCP ซึ่งเปลี่ยนได้

## ข้อจำกัด

- ใช้ได้บน Windows เท่านั้น เพราะตัวเลือก `-n` และ `-w` ของ ping เป็นแบบ Windows
- สแกนช้า ครบ 254 IP ใช้ประมาณ 2.4 นาที เพราะต้องรอ IP ที่ไม่มีเครื่องทีละตัว
- เช็กแค่ 5 พอร์ต ถ้าเครื่องเปิดพอร์ตอื่นไว้ โปรแกรมจะไม่เห็น
- อุปกรณ์ที่ตั้งค่าไม่ให้ตอบ ping จะถูกมองว่า offline และไม่ถูกเช็กพอร์ต
- ถ้าตั้ง timeout สั้นเกินไป อุปกรณ์ที่ตอบช้า เช่น มือถือที่พักหน้าจออยู่ อาจถูกตัดสินผิดว่า offline
- บอกได้แค่ IP ยังไม่บอกว่าเป็นอุปกรณ์อะไร

## จริยธรรม

โปรแกรมนี้ใช้สแกนเฉพาะเครือข่ายของตัวเองเท่านั้น ถ้าไปทำกับเครือข่ายของคนอื่นโดยไม่ได้รับอนุญาต ถึงจะยังไม่ได้เข้าไปข้างใน ก็ไม่เหมาะสมและอาจผิดกฎหมาย

## สิ่งที่จะพัฒนาต่อ

- Threading: ส่ง ping ไปหลายเครื่องพร้อมกัน เช่น ครั้งละ 50 เครื่อง ผมคำนวณไว้ว่าจะลดเวลาสแกน 254 IP จากประมาณ 2.4 นาที เหลือไม่กี่วินาที
- บันทึกรายงานลงไฟล์ เพื่อเทียบผลแต่ละวันได้
- ให้ผู้ใช้พิมพ์เลือกเครือข่ายเองด้วย `input()` แทนการแก้โค้ด
- รองรับ Mac และ Linux
- เตือนเมื่อเจอพอร์ตเสี่ยงอย่าง 22 หรือ 3389 เปิดอยู่
